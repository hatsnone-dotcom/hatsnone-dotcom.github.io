Brainsparks Uploader - Stand 26. Juli 2026

Brainsparks Uploader ist eine private, nicht oeffentlich zugaengliche Automatisierungsanwendung. Sie wird ausschliesslich vom Betreiber des Kanals Brainsparks verwendet, um eigene Video-Inhalte auf TikTok, YouTube und Instagram zu veroeffentlichen.

Es werden keine Daten von Drittnutzern erhoben, gespeichert oder verarbeitet. Die Anwendung hat keine Endnutzer ausser dem Betreiber selbst.

1. Verantwortliche Stelle

Der Betreiber des Kanals Brainsparks, erreichbar ueber die offiziellen Kanaele auf YouTube, TikTok und Instagram.

2. Welche Daten verarbeitet werden

DatenartZweck
OAuth-Zugriffstoken (TikTok, YouTube, Instagram)Authentifizierung beim Video-Upload auf den eigenen Kanal
Selbst erstellte VideodateienVeroeffentlichung als Kurzvideo-Content
Video-Titel und BeschreibungstextAnzeige des Videos auf der jeweiligen Plattform

3. Speicherort

Alle Zugangsdaten und generierten Inhalte werden lokal bzw. auf einem eigenen Server des Betreibers gespeichert. Es erfolgt keine Weitergabe an Dritte ausser den genannten Plattformen (TikTok, YouTube, Instagram) zum Zweck der Veroeffentlichung.

4. Drittanbieter-APIs

  • TikTok Content Posting API - Video-Upload auf den eigenen TikTok-Kanal
  • YouTube Data API v3 - Video-Upload auf den eigenen YouTube-Kanal
  • Instagram Graph API - Video-Upload auf den eigenen Instagram-Kanal

Fuer die Verarbeitung durch diese Plattformen gelten deren eigene Datenschutzbestimmungen.

5. Speicherdauer und Loeschung

Zugriffstoken werden bis zum Widerruf durch den Betreiber gespeichert. Eine Loeschung ist jederzeit durch Entfernen der Zugangsdaten moeglich.

6. Keine Datenerhebung bei Endnutzern

Da die Anwendung keine oeffentliche Schnittstelle besitzt, werden keine Daten von Zuschauern, Followern oder Plattformnutzern erhoben.
